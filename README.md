# fraud-risk-decision-support-
This project implements a fraud risk scoring model using Logistic Regression in RapidMiner. The process file (.rmp) allows full reproducibility of the decision-support pipeline without requiring Python code. The model is designed for risk prioritisation, not automated blocking, aligned with EU regulatory expectations (GDPR, AML).
